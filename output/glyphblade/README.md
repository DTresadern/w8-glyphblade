# Gothic side-scroller concept set

Four location mockups: graveyard, chapel, crypt and castle garden. The remaining fourteen PNGs are standalone concepts for a hunter, skeleton, nun, ghost, zombie and nine environment pieces. Each PNG has a JSON file with the exact generation prompt and provenance. The rotated user screenshot used as reference is in `../../references/glyphblade/`.

The location mockups are flattened images, not separately layered scenes. Character and prop PNGs are static concepts, not animation sheets. The tree is a standalone layer candidate, not a complete parallax background. Assets are generated at varied sizes and may need clean-up, consistent scale, pivots and animation for game use. Tile and fence concepts are not verified seamless and need cropping and edge matching before use.

## Expansion

Files 19–30 add two fire goblins, two water spirits, castle architecture, furnishings and a five-phase moon sheet. The battlement ends differ and are not a seamless tile. The moon sheet contains a red full moon; the lighter moon before it is gibbous. `expansion-overview.jpg` shows the new pieces.
