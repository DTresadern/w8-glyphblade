# Layered scene reconstructions

Four scene folders contain source copies, reconstructed far plates, three independently movable transparent example prop layers, reusable props and character images, foreground ground slices and composited previews. Start with each scene’s `README.md` and `manifest.json`.

The original concepts are flattened. Hidden pixels and exact object masks cannot be recovered; generated background plates and existing props are reconstructions. The plates retain internal depth baked together, and are not seamless loops. Ground cells preserve their original order and are not generally interchangeable seamless tiles. These are prototype-ready building blocks that need art and seam cleanup for production.
