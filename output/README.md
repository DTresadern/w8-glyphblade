# Ruined chapel asset set

Twenty original AI-generated, static fantasy asset concepts: eight creatures and twelve architectural props or items. Browse `asset-overview.jpg` or the individual transparent PNGs in `sprites/`. The built-in image generator produced each image separately; `prompts.json` and the companion JSON beside each PNG record the prompts and provenance.

These are large, pixel-style illustrations, not an animated sprite sheet or a unified low-resolution pixel grid. Dimensions, apparent pixel sizes, perspective and scale vary. They may need manual cleanup, consistent scaling, pivots and animation before use in a game.

Visual research and rights information are in `../references/README.md`. The downloaded game artwork was studied as reference; it was not supplied to the generator or included in the generated sprites.
